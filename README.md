# 🍓 鲜果乐园 — fruit

一个纯前端的水果电商演示网站：使用 emoji 作为商品头像，具备商品介绍与完整下单流程。

## 功能

- 🛒 商品列表：14 种水果，分类筛选 / 搜索 / 排序
- 📖 商品介绍：卖点文案、营养成分、保存方式、买家评价
- 🧺 购物车：数量增减、库存限制、满 ¥39 免运费进度条
- 📦 下单：收货信息校验 → 运费自动计算 → 订单回执 →「我的订单」列表
- 💾 localStorage 持久化购物车与订单

## 本地运行

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```

或直接双击 `index.html`（无任何构建依赖）。

## 技术

纯 HTML / CSS / JavaScript，零依赖、零构建。

> 本站为演示项目，下单与支付均为模拟。
